# Security Policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Security issues should be reported privately by email to:

**subirthecoder35@gmail.com**

Please include enough information to reproduce and assess the issue, such as:

- affected component or endpoint
- affected version, branch, or commit
- steps to reproduce
- expected and actual behavior
- security impact
- proof of concept, if available and safe to provide

Please avoid publicly disclosing exploit details while a security issue is being assessed and remediated.

## Feature development and general contributions

Security reporting is separate from normal project development. Feature requests, development discussions, documentation improvements, bug fixes, tests, and other non-security contributions are welcome through the normal GitHub contribution workflow.

For general project discussions, use GitHub issues or discussions. Pull requests are welcome for normal feature and development work.
