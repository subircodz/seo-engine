# Code of Conduct

## Our standard

Contributors, maintainers, and participants are expected to communicate respectfully and constructively.

We welcome people contributing through issues, discussions, reviews, documentation, tests, and pull requests.

Unacceptable behavior includes harassment, personal attacks, discrimination, deliberate intimidation, and disruptive conduct that prevents others from participating constructively.

## Enforcement

Project maintainers may remove comments, close discussions or pull requests, or restrict participation when necessary to keep the project constructive and safe.

For security vulnerabilities, do not use public GitHub channels. Follow the private reporting process in [SECURITY.md](SECURITY.md).
