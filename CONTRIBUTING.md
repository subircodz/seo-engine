# Contributing

Contributions to SEO Engine are welcome.

## What to contribute

Useful contributions include:

- feature development
- bug fixes
- tests and test coverage
- documentation improvements
- performance and reliability improvements
- developer tooling and CI improvements

Please keep changes focused, tested, and consistent with the existing architecture and documented application contract.

## Discussions and feature ideas

Use GitHub Issues and Discussions for feature ideas, questions, design discussions, and general development topics.

For normal development work, pull requests are welcome.

## Security vulnerabilities

Do **not** report security vulnerabilities through public GitHub Issues, Discussions, or pull requests.

Report security vulnerabilities privately by email:

**subirthecoder35@gmail.com**

See [SECURITY.md](SECURITY.md) for the security reporting policy.

## Pull requests

Before opening a pull request:

1. Keep the change scoped to its purpose.
2. Add or update tests when behavior changes.
3. Keep documentation and the application contract aligned with the actual implementation.
4. Ensure the repository CI checks pass.
5. Do not include secrets, credentials, private data, or generated local artifacts.
